# EVOLVIA — Website

Responsive, modern landing page for EVOLVIA, an international digital studio.

## Files
- `index.html` — page structure and content
- `style.css` — styling and responsive layout
- `script.js` — mobile navigation, reveal animations, current year
- `assets/evolvia-logo.png` — original EVOLVIA logo used in the header, about section, footer, and favicon

## Services shown
- Web Development
- Graphic Design
- Video Editing
- Database Development

## Publish with GitHub and Vercel
1. Unzip this package.
2. Upload all files and the `assets` folder to the root of your GitHub repository. Do not upload only the HTML file.
3. Keep the main page named exactly `index.html`.
4. Vercel should redeploy automatically if connected to the repository.
5. Open the live site and test the menu, WhatsApp button, Instagram button, and mobile layout.
