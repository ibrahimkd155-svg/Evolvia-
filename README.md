# EVOLVIA — Website

A responsive, modern landing page for EVOLVIA, an independent digital studio.

## Files
- `index.html` — page structure and content
- `style.css` — colors, responsive layout, and visual styling
- `script.js` — mobile navigation, reveal animations, and current year

## Publish with GitHub and Vercel
1. Create or open your GitHub repository.
2. Upload **all four files** to the repository's root (not inside another folder).
3. Confirm that the main page is named exactly `index.html`.
4. If the repository is connected to Vercel, it should deploy automatically.
5. Open the deployment URL and check the mobile layout and contact link.

## Before publishing
In `index.html`, search for `hello@evolvia.digital` and replace it with your real business email. The current email is a placeholder; it may not receive messages unless you own/configure that address.

The page loads DM Sans and Manrope from Google Fonts. If external fonts are unavailable, it falls back to system sans-serif fonts.

## Brand palette
- Deep navy: `#0B1220`
- Electric blue: `#3478F6`
- White: `#F7F9FF`
- Accent cyan: `#57D7FF`

## Notes
- This is a front-end landing page; it does not include a CMS, database, client login, or working form backend.
- All content is in English for an international audience.
